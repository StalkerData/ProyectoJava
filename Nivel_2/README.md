# 👾 Nivel 2: Programación Orientada a Objetos y Lógica de Negocio Avanzada

## Descripción del nivel
Este directorio contiene el núcleo de lógica de negocio (Backend Core) desarrollado 100% en Java. El objetivo de este nivel es demostrar un dominio absoluto de la Programación Orientada a Objetos (POO), estructuras de datos, características modernas de Java y la calidad del software mediante pruebas unitarias. A través de tres proyectos independientes, se aplican principios SOLID, Patrones de Diseño y arquitecturas limpias, sentando las bases necesarias para el desarrollo empresarial escalable.

## Proyectos desarrollados

### 1. 📚 [Sistema de Gestión de Biblioteca](./Sistema_Gestion_Biblioteca/README.md)
Motor de lógica para administrar inventarios y préstamos.
*   **Enfoque técnico:** Abstracción, Herencia, Colecciones eficientes (`HashMap`, `ArrayList`) y manejo de Excepciones personalizadas (Fail-Fast).

### 2. ⚔️ [Simulador de Batallas RPG](./rpg_simulator/README.md)
Motor de batallas por turnos con cálculo de probabilidades y estados.
*   **Enfoque técnico:** Polimorfismo puro, uso avanzado de Genéricos (`<T>`) para colecciones seguras (Type Safety) y encapsulamiento estricto de reglas de negocio.

### 3. 🛒 [Procesador de Pedidos E-commerce](./ecommerce_processor/README.md)
Sistema de cálculo de impuestos y pasarela de pagos simulada.
*   **Enfoque técnico:** Patrón de Diseño *Strategy* (desacoplamiento de métodos de pago), Programación Funcional (Streams y Lambdas) y modelado inmutable con `Records`.

## Objetivos técnicos alcanzados
*   **Dominio de POO y SOLID:** Aplicación de abstracción, encapsulamiento, herencia y polimorfismo, respetando principios como Open/Closed y Single Responsibility.
*   **Java Moderno:** Implementación de características recientes del lenguaje como `Records`, `Streams`, `Lambdas` y `Method References`.
*   **Estructuras de Datos Seguras:** Manejo avanzado de colecciones y genéricos para evitar errores de casteo en tiempo de ejecución.
*   **Testing y Calidad (TDD):** Cobertura de código mediante pruebas unitarias con **JUnit 5**, validando caminos felices, casos borde y lanzamiento de excepciones.
